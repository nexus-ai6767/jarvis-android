JARVIS Android V2.1 - Offline AI

- Android-native on-device Gemma 2B CPU inference via MediaPipe tasks-genai.
- No Gemini API key required.
- No PC/Ollama required after the model is installed.
- First launch requires internet once to download the model into private app storage.
- After the model is downloaded, AI generation works offline.
- Voice input uses Android SpeechRecognizer; availability may depend on the device's speech service.
- Voice output uses Android TextToSpeech.

The app uses the Gemma model under its applicable license/terms. Do not redistribute the model file unless its license permits it.
